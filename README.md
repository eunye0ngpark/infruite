# infruite · 达人营销 OMS

一个独立的达人营销运营原型，包含工作台、订单管理、达人池和权限管理。每次打开页面默认进入工作台。页面数据保存在当前浏览器的本地存储中。

首次打开会生成 20 倍演示规模：100 位运营、60 个小组、220 笔订单和 180 位达人档案。运营配比为 1 位管理员、3 位组长和 96 位组员。订单和达人列表每页显示 20 条。

## 运行

在本目录执行：

```sh
sh start.sh
```

然后打开 <http://127.0.0.1:4174>。有 Node.js 时使用项目内的轻量服务器；没有 Node.js 时会使用 Python 3 提供静态页面。

## 当前版本

- 演示数据仅保存在当前浏览器，不会同步给其他人。
- 公开链接允许访问者打开页面；每位访问者仍使用各自浏览器中的演示数据。
- 达人邮件操作会记录为“已发送”，不会连接或发送真实邮件。
- 达人名单模板使用 Excel 可打开的 CSV 格式，导入时会检查必填字段、渠道和重复达人。
- 入库过期检查在页面打开时和页面运行期间执行；服务端定时任务尚未接入。
- 当前页面用于流程演示；团队登录、服务端数据库、邮件接入和自动定时任务还未接入。
